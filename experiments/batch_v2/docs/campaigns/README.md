1. Create docs/campaigns/<campaign-id>/.
2. Copy the [campaign README](../templates/campaign-readme.md), [task definition](../templates/task-definition.md) and [journal](../templates/run-journal.md).
3. Add one index entry here with task, dataset version, status and relative link.
4. Create numbered round records only as those rounds are planned.

Example entry format, not a real experiment:
- campaign-id — task purpose — dataset version — status — link to campaign README.

See [the handbook](../README.md) and [storage instructions](../records-and-handoffs.md). Do not put fabricated initial results in this index.
