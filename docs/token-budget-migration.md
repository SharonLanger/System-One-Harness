# Strict LAYA input-budget migration

Strict input-budget validation rejects requests that LAYA previously shortened silently. A failure observed during a building-block call can originate in the shared LAYA prediction boundary. Building blocks intentionally pass this exception unchanged. Find the matching budget ERROR event using its request ID and inspect the named question, option, and boundary. Shortening state does not fix an oversized instruction or option. The existing file_method_context flow is a sandbox and may return generic model_error. Do not disable validation, silently trim input, or increase model limits just to restore an old sandbox expectation.

`InputTokenBudgetExceeded` means exact inspection measured loss. `InspectionUnavailable` means the runtime/profile/checkpoint/capability cannot be verified; it does not mean the text is too long. `InspectionFailed` means an unexpected inspection problem prevented a reliable decision. All inherit `InputBudgetError`; `error.report` is a JSON-safe independent snapshot. These errors are distinct from `ResponseError`, which concerns SDK output. The report's token counts are pre-inference requirements, not billed usage. Unknown measurements are null.

A custom predict-only agent needs an explicit keyword-only inspection provider. The registry owns that capability and the loader. A wrapper must forward verified inspection of its actual wrapped agent; requested model names do not prove identity. Plumbing-test providers may be injected in tests and explicitly mocked examples, but are never selected by production configuration. No automatic mock detection or validation bypass is supported.

Only the flow may decide whether to shorten, retry, skip or change blocks. This change adds none of those policies. The unchanged successful response is still the normal answers JSON. A rejected call sends no question to request inference; lazy loading or optional SDK warmup may already have happened. Live Mac and code-model qualification require separate actual runtime evidence.
